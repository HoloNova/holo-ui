# Chart Artifact

### Description
A dependency-free inline-SVG chart (line / bar / area / scatter / radar / gauge) for local metrics — eval curves (precision/recall/F1 radar), 2D embedding projections (scatter), drift-over-time, latency/tok-s. Driven by useEvaluateModel/useReindex or any local numbers. No charting library, no server.

### Tokens
- scale: `standard`
- placement: `embedded`
- interaction: `output`
- lifecycle: `persistent`
- motion: `none`
- category: `data`
- runtime: `react`

### When to use
Use `chart-artifact` when a dependency-free inline-svg chart (line / bar / area / scatter / radar / gauge) for local metrics — eval curves (precision/recall/f1 radar), 2d embedding projections (scatter), drift-over-time, latency/tok-s. driven by useevaluatemodel/usereindex or any local numbers. no charting library, no server.

### When not to use
Do not use when heavy proprietary server-side orchestrators or non-React plain HTML environments are required.
