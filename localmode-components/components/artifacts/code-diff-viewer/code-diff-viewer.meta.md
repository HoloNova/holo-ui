# Code Diff Viewer

### Description
A unified or side-by-side text/code diff of two local strings (before/after of redacted, translated, or transformed text). Additions/deletions highlighted, computed client-side via a dependency-free LCS line diff. The text analog of BeforeAfterImageViewer. No ML hook, no server.

### Tokens
- scale: `region`
- placement: `embedded`
- interaction: `output`
- lifecycle: `persistent`
- motion: `transition`
- category: `code`
- runtime: `react`

### When to use
Use `code-diff-viewer` when a unified or side-by-side text/code diff of two local strings (before/after of redacted, translated, or transformed text). additions/deletions highlighted, computed client-side via a dependency-free lcs line diff. the text analog of beforeafterimageviewer. no ml hook, no server.

### When not to use
Do not use when heavy proprietary server-side orchestrators or non-React plain HTML environments are required.
