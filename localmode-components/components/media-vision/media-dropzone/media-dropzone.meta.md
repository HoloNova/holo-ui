# Media Dropzone

### Description
A drag-and-drop + click-to-browse image upload zone with idle / drag-over / processing states, accept-list + max-size validation via validateFile, an "add another" variant, and an onFiles(File[]) callback.

### Tokens
- scale: `standard`
- placement: `embedded`
- interaction: `input`
- lifecycle: `persistent`
- motion: `none`
- category: `composer`
- runtime: `react`

### When to use
Use `media-dropzone` when a drag-and-drop + click-to-browse image upload zone with idle / drag-over / processing states, accept-list + max-size validation via validatefile, an "add another" variant, and an onfiles(file[]) callback.

### When not to use
Do not use when heavy proprietary server-side orchestrators or non-React plain HTML environments are required.
