# Before / After Image Viewer

### Description
Compare an original image with a transformed result — a two-panel grid with checkerboard transparency (shipped inline) or a segmented Original / Enhanced toggle. Pairs with useImageToImage / useSegmentImage.

### Tokens
- scale: `region`
- placement: `embedded`
- interaction: `output`
- lifecycle: `persistent`
- motion: `transition`
- category: `content`
- runtime: `react`

### When to use
Use `before-after-image-viewer` when compare an original image with a transformed result — a two-panel grid with checkerboard transparency (shipped inline) or a segmented original / enhanced toggle. pairs with useimagetoimage / usesegmentimage.

### When not to use
Do not use when heavy proprietary server-side orchestrators or non-React plain HTML environments are required.
