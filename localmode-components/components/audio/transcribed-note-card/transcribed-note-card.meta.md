# Transcribed Note Card

### Description
A transcription list item pairing transcript text with inline <audio> playback — relative timestamp (hover -> absolute), transcribed body, and a hover-revealed delete — plus a transcribing… placeholder variant (WaveformActivityBars + label) that morphs into the populated card. The canonical useOperationList-backed STT list pattern; driven by useTranscribe.

### Tokens
- scale: `standard`
- placement: `embedded`
- interaction: `output`
- lifecycle: `persistent`
- motion: `none`
- category: `content`
- runtime: `react`

### When to use
Use `transcribed-note-card` when a transcription list item pairing transcript text with inline <audio> playback — relative timestamp (hover -> absolute), transcribed body, and a hover-revealed delete — plus a transcribing… placeholder variant (waveformactivitybars + label) that morphs into the populated card. the canonical useoperationlist-backed stt list pattern; driven by usetranscribe.

### When not to use
Do not use when heavy proprietary server-side orchestrators or non-React plain HTML environments are required.
