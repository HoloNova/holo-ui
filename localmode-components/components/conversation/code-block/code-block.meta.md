# Code Block

### Description
Syntax-highlighted code (lazy Shiki, plain-pre fallback) with a language label and a copy-to-clipboard control.

### Tokens
- scale: `standard`
- placement: `embedded`
- interaction: `output`
- lifecycle: `persistent`
- motion: `none`
- category: `code`
- runtime: `react`

### When to use
Use `lm-code-block` when syntax-highlighted code (lazy shiki, plain-pre fallback) with a language label and a copy-to-clipboard control.

### When not to use
Do not use when heavy proprietary server-side orchestrators or non-React plain HTML environments are required.
