# Loader

### Description
A small family of busy indicators (dots / pulse / typing / spinner) plus a Shimmer skeleton-text variant, shown while a local model warms up or streams its first token.

### Tokens
- scale: `standard`
- placement: `embedded`
- interaction: `output`
- lifecycle: `transient`
- motion: `css-loop`
- category: `content`
- runtime: `react`

### When to use
Use `loader` when a small family of busy indicators (dots / pulse / typing / spinner) plus a shimmer skeleton-text variant, shown while a local model warms up or streams its first token.

### When not to use
Do not use when heavy proprietary server-side orchestrators or non-React plain HTML environments are required.
