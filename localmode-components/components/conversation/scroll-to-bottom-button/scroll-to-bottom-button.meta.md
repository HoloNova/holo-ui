# Scroll To Bottom Button

### Description
A floating scroll-to-bottom affordance tied to a chat container's scroll state — appears when the user scrolls up, scrolls to and pins the latest content. Pairs with a ScrollAnchor pin element. Data source: useChat.

### Tokens
- scale: `micro`
- placement: `dock`
- interaction: `control`
- lifecycle: `persistent`
- motion: `none`
- category: `action`
- runtime: `react`

### When to use
Use `scroll-to-bottom-button` when a floating scroll-to-bottom affordance tied to a chat container's scroll state — appears when the user scrolls up, scrolls to and pins the latest content. pairs with a scrollanchor pin element. data source: usechat.

### When not to use
Do not use when heavy proprietary server-side orchestrators or non-React plain HTML environments are required.
