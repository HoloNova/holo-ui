# Suggestions

### Description
A horizontal row of selectable prompt chips; each Suggestion invokes a callback with its text to seed the composer.

### Tokens
- scale: `standard`
- placement: `embedded`
- interaction: `output`
- lifecycle: `persistent`
- motion: `none`
- category: `content`
- runtime: `react`

### When to use
Use `suggestions` when a horizontal row of selectable prompt chips; each suggestion invokes a callback with its text to seed the composer.

### When not to use
Do not use when heavy proprietary server-side orchestrators or non-React plain HTML environments are required.
