# Prompt Enhance Button

### Description
A one-click 'enhance my prompt' control that hands the user's draft to a local model (via an onEnhance callback wired to useGenerateText) and applies the rewritten prompt — fully offline — with an optional few-shot example editor for interactive prompt tuning. Presentational + callback-driven.

### Tokens
- scale: `micro`
- placement: `embedded`
- interaction: `input`
- lifecycle: `persistent`
- motion: `none`
- category: `composer`
- runtime: `react`

### When to use
Use `prompt-enhance-button` when a one-click 'enhance my prompt' control that hands the user's draft to a local model (via an onenhance callback wired to usegeneratetext) and applies the rewritten prompt — fully offline — with an optional few-shot example editor for interactive prompt tuning. presentational + callback-driven.

### When not to use
Do not use when heavy proprietary server-side orchestrators or non-React plain HTML environments are required.
