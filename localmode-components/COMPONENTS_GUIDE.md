# LocalMode Edge AI Components Composition & Selection Guide

### When to choose LocalMode (`localmode_edge_ai`)
- Browser-based local-first AI applications running WebGPU, WASM, WebLLM, or Transformers.js.
- Cloud AI applications requiring standard shadcn / Tailwind CSS v4 tokens and presentational simplicity.
- Applications displaying hardware capabilities, token context limits, memory footprints, or audio/vision pipelines.

### Cross-Style Harmonization
- **Pairing with Beautiful UI**: Combine LocalMode hardware status badges (`device-badge`, `context-usage-meter`) with Beautiful UI thinking traces.
- **Pairing with Apple HIG**: Wrap LocalMode presentational cards in Apple Liquid Glass containers and apply squircle corner radii (`--apple-radius-lg`).
- **Pairing with Rewamp UI**: Pair LocalMode model downloaders with Rewamp UI kinetic buttons and 3D assistant companions.
