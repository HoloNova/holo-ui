# 🧩 Apple HIG 全部组件与模式总览 (Complete HIG Component Index)

> **本文件整合自**：`https://developer.apple.com/design/human-interface-guidelines/components`  
> **核心用途**：离线掌握苹果官方全套 40+ 核心交互组件的设计规则、适用场景与设计禁忌，作为做交互决策时的快速字典。

---

## 1. 结构与导航栏 (Bars & Navigation)

| 组件 | 核心规则与设计禁忌 | 常用属性/尺寸 |
|:---|:---|:---|
| **Navigation Bar (导航栏)** | 页面顶部导航。支持常态紧凑模式与滚动下拉大标题（Large Title）模式。大标题在页面向上滑动时平滑收缩到标题栏居中。 | 高度 44pt (紧凑) / 96pt (大标题) |
| **Tab Bar (分页标签栏)** | 位于移动端屏幕最底部。仅用于顶层核心业务分流（3~5 个为宜）。图标与文字紧凑结合，选态高亮，非选态置灰。 | 高度 49pt~83pt (含 Home Bar) |
| **Toolbar (工具栏)** | 放置针对当前屏幕上下文的操作按钮。与 Tab Bar 互斥，通常在底部或顶部并存。 | 高度 44pt |
| **Search Bar (搜索栏)** | 可作为导航栏内置部件或独立模块。必须配备“取消”文本或清除“X”按钮，支持实时建议词下拉。 | 高度 36pt (输入框) |
| **Status Bar (系统状态栏)** | 展示时间、信号与电池。内容必须使用浅色或深色文本确保与底层背景产生高对比度。 | 动态适配 Safe Area |

## 2. 内容呈现与容器 (Views & Presentation)

| 组件 | 核心规则与设计禁忌 | 常用属性/尺寸 |
|:---|:---|:---|
| **Collection View (网格流)** | 用于复杂网格、相册、瀑布流。支持组合布局（Compositional Layout），保持统一的内边距与间距律。 | 8pt 栅格律 |
| **Table View / List (列表)** | 分为 Plain（平铺）与 Inset Grouped（带圆角卡片分组）。卡片圆角通常为 10~16px，首尾行自动切圆角。 | 单元格最小行高 44pt |
| **Card (卡片)** | 聚合单一主题信息的自包含容器。使用低透明度阴影和微弱边框，禁止生硬厚边框。 | 边距 16px，圆角 16~20px |
| **Scroll View (滚动视图)** | 滚动至两端时必须有经典的 Apple 弹性阻尼回弹（Rubber Banding）。 | 惯性衰减动效 |
| **Split View (分栏视图)** | iPad 与 macOS 核心。支持侧边栏、主视图、详情视图两栏或三栏平滑收折。 | 侧栏默认宽 260~320px |
| **Sheet (抽屉卡片)** | 从底部升起的模态容器。顶部必须有拖拽条（Grabber），支持 50% 与 90% 挡位（Detents）。 | 顶部圆角 20~28px |

## 3. 控制与交互控件 (Controls & Inputs)

| 组件 | 核心规则与设计禁忌 | 常用属性/尺寸 |
|:---|:---|:---|
| **Button (按钮)** | 四种视觉层级：Filled（强调主色）、Tonal/Tinted（浅主色底）、Gray（灰色次级）、Plain（无底色纯文本）。禁止在同一屏幕放多个同级 Filled 按钮。 | 触控区最小 44×44pt |
| **Segmented Control (分段选择器)** | 互斥切换 2~5 个平级筛选视图。滑块带背景物理滑动与轻柔投影。 | 高度 28~32pt |
| **Switch (开关/切换器)** | 仅用于二元即时生效的开关（开/关），不可用于需要再按“保存”的表单选项。开态为 System Green。 | 尺寸 51×31pt |
| **Slider (滑块)** | 连续数值微调（如音量、亮度、曝光）。拖拽滑块滑过时音量可伴随触觉微震动。 | 轨道高度 4pt |
| **Stepper (步进器)** | 适合小幅度、离散数值递增递减（如数量、人数）。 | 尺寸 94×29pt |
| **Text Field (单行输入框)** | 必须配备占位符（Placeholder），内容聚焦时边框或高光微变。禁止无外框隐蔽设计。 | 高度 36~44pt |

## 4. 浮层、反馈与菜单 (Menus & Feedback)

| 组件 | 核心规则与设计禁忌 | 常用属性/尺寸 |
|:---|:---|:---|
| **Context Menu (上下文长按菜单)** | 长按或右键弹出。被选中的卡片浮起高亮，菜单选项垂直列出，危险动作（删除）在最底标红。 | 毛玻璃材质，圆角 14px |
| **Action Sheet (操作表)** | 底部弹出多个选项列表。取消按钮必须物理独立在最下方成单张卡片。 | 选项高 56pt |
| **Alert (警告弹窗)** | 极少数核心阻断。最多 2~3 个操作，主确认按钮字重加粗。禁止滥用做普通提示。 | 固定最大宽 270pt |
| **Toast / Banner (浮动提醒)** | 顶部灵动岛或胶囊通知。不可遮挡主要操作，3~4 秒后自动隐退。 | 胶囊圆角 9999px |
| **Haptics (触觉反馈)** | 与视觉动效配合。提供 Success、Warning、Error、Impact（Light/Medium/Heavy）四级震动节奏。 | 物理触感 |
